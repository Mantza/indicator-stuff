Methodology

This tracker is based on an exhaustive dataset of all English-language replies from Grok in response to users tagging @grok to fact-check posts on X (formerly Twitter) between January 1 and February 28, 2026. Data was collected via the X API using the approach described in Mantzarlis, Renault, Mosleh & Rand ("@Grok Is This True? LLM-Powered Fact-Checking on Social Media," 2026).

The dataset captures instances in which a user replied to or quote-tweeted a post while mentioning @grok with an explicit or implicit request for verification (e.g., "is this true?", "fact check this," etc.).

For each day (defined in UTC), the tracker identifies the tweet that received the highest number of such Grok fact-checking replies — the day's "main character." Grok's verdict for each tweet is classified programmatically based on the language of its reply (e.g., "No, this claim is false" → false; "Yes, reports confirm" → true; partial confirmations → mixed; ambiguous responses → unclear). The "Top Grok fact-check" shown on each card is the most-engaged-with Grok reply to that tweet, linked to its original post on X.
